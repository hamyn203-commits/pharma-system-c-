# 💊 نظام إدارة الصيدلية | Pharmacy Management System

مستودع برمجى مخصص لإدارة العمليات اليومية داخل الصيدليات، يهدف إلى تنظيم حركة المخزون، المبيعات، والفواتير بكفاءة عالية.

## 🚀 المميزات الرئيسية (Features)
* **إدارة المخزون:** إضافة وتحديث الأدوية والتحقق من تواريخ الصلاحية.
* **نظام المبيعات:** إنشاء الفواتير وحساب الإيرادات اليومية.
* **إدارة المستخدمين:** صلاحيات مخصصة للمدير، والصيدلي، والكاشير.
* **التقارير:** استخراج تقارير دورية عن المبيعات والأدوية الأكثر طلباً.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **قاعدة البيانات:** [SQL Server / MySQL / SQLite]
